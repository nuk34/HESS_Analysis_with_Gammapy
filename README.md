# H.E.S.S. Analysis with Gammapy Notebooks

> **Gammapy version:** Gammapy v2.1

Gammapy installation guide available at [https://docs.gammapy.org/2.1/getting-started/index.html](https://docs.gammapy.org/2.1/getting-started/index.html)

The order of these notebooks are as follows:

1. **`FirstLook`**  Getting the data and learning the basics

2. **`SkyMaps`**  Making maps and exclusion regions

3. **`Spectrum`**  Spectra and flux 

4. **`Morphology`**  Modelling the shape of an object and 3D-analysis
 
5. **`LightCurve`**  Checking for variability

6. **`Project`**  Do your own analysis based on what you have learnt
